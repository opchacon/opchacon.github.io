# Oscar Chacón-Rivera — academic homepage

This is a simple GitHub Pages website: https://opchacon.github.io/

## Files

- `index.html` contains the content and navigation.
- `style.css` controls fonts, colors, spacing and mobile layout.

## How to edit

1. Open `index.html` in GitHub and click the pencil icon.
2. Change the text inside tags like `<p>...</p>` or `<h2>...</h2>`.
3. Commit your changes to the branch. To publish, merge your pull request into `main`.
4. To customize the colors or width, edit `--accent` and `--page-width` at the top of `style.css`.
